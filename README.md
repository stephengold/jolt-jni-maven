[The jolt-jni-maven project][project] provides
a sample desktop applications
for [the Jolt-JNI physics library][joltjni],
built using Maven and Java.

Complete source code is provided under
[a 3-clause BSD license][license].


## How to build jolt-jni-maven from source

1. Install Java and Maven, if you don't already have them.
2. Download and extract the jolt-jni-maven source code from GitHub:
  + using [Git]: `git clone https://github.com/stephengold/jolt-jni-maven.git`
3. `cd jolt-jni-maven`
4. `mvn package`
